How I work

Care for the part between idea and everyday use.

Good product work is a series of small, deliberate decisions—especially after the first release.

01 / Understand

Start with the workflow

Find the real friction, then shape the interface around what people are already trying to do.

02 / Build

Make the whole system fit

Connect the UI, application logic, storage, and integrations so the experience feels coherent.

03 / Improve

Keep it dependable

Handle the awkward edges—slow networks, empty states, recovery paths, and future maintenance.
